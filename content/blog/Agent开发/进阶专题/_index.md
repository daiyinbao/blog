## 进阶专题

前面的十篇把 Agent 从概念讲到了工程化落地，主线是"把 Agent 做出来"。这一组六个专题往深水区走，讲的是**把 Agent 做扎实**：内部怎么运转、怎么规划、怎么安全地执行代码和 SQL、怎么管住长任务，最后怎么扛住生产流量。

每个专题都延续前面的风格：**先讲原理，再落到可运行的代码**。

- 一、Agent Runtime 设计
- 二、Agent 规划与推理
- 三、Agent 与代码执行
- 四、Agent 与数据库
- 五、Agent 长任务管理
- 六、Agent 生产化
