## 一.微服务下的登录模块

本文基于一个真实的企业级 IAM（Identity & Access Management）项目，系统性拆解登录模块在**高并发、高安全**场景下的设计思路与工程实现

目标读者：

- 有一定 Spring Boot / Java 后端经验
- 希望把“能用的登录”升级为“可扩展、可风控、可演进的登录体系”1

### 1.模块划分

#### 1.1网关模块gataway-service

该模块主要用于接收前端发过来的请求，分发请求需要业务到对应模块。

该模块的功能：

分发请求。使用spring cloud alibaba gateway 组件实现请求分发

辨识token的合法性。

使用openfeignn 实现模块之间的功能调用

这篇文章对该模块不做详细讲解！

#### 1.2 业务模块iam-service

该模块是完成登录相关业务的主要处理模块

当网关的请求到达该业务时，会根据api调用不同的service，完成用户需求。并将数据返回给前端，是核心的业务层！

### 2.实现业务前瞻

业务层：

0客户端请求
 ↓
① 图形验证码校验
② 短信验证码校验
③ 解析客户端 IP
④ IP 白名单 / 黑名单校验
⑤ 密码复杂度校验
⑥ Redis 登录互斥锁
⑦ 是否已登录校验
⑧ 查询用户
⑨ 账号是否被锁定
⑩ 密码是否过期
⑪ 校验密码
 ├─ 失败 → 失败次数 + 账号锁定
 └─ 成功
⑫ 重置登录状态
⑬ 生成 JWT（access + refresh）
⑭ 绑定 Redis Session（单端登录）
⑮ 清理旧 Token
⑯ 缓存新 Token
⑰ 返回登录结果

这是处理登录的主要业务方法：

```java
/*该注解是写日志的，这里不用深究*/
@IamAudit(action = "用户登录", detail = "账户密码 + 短信双因子登录")
public AuthResponse login(AuthRequest request, HttpServletRequest servletRequest) {
    /*先校验图片验证码和短信验证码*/
    captchaService.validate(request.getCaptchaId(), request.getCaptchaCode());
    smsCodeService.verifyLoginCode(request.getUsername(), request.getSmsCode());
    /*获取客户端ip*/
    String clientIp = resolveClientIp(servletRequest);
    /*校验ip是否在白名单和黑名单中*/
    enforceIpPolicy(clientIp);
    /*密码是否合法*/
    validatePasswordComplexity(request.getPassword());
    loginSessionService.acquireLoginLock(request.getUsername());
    try {
        /*检验是否已登录，if login ，can't login again*/
        loginSessionService.ensureLoggedOut(request.getUsername());
        /*查询用户是否存在*/
        IamUser user = getUserByUsername(request.getUsername());

        ensureAccountAvailable(user);
        /*判断密码是否过期*/
        ensurePasswordNotExpired(user);
        if (!isPasswordMatched(request.getPassword(), user.getPassword())) {
            /*密码错误需要进行的业务*/
            handleLoginFailure(user);
            throw new BusinessException(ErrorCode.UNAUTHORIZED);
        }
        resetLoginState(user, clientIp);
        /*设置token的有效期*/
        long expireAt = Instant.now().plusSeconds(jwtProvider.getAccessTokenTtl()).toEpochMilli();
        String token = jwtProvider.generateToken(request.getUsername(), jwtProvider.getAccessTokenTtl());
        String refreshToken = jwtProvider.generateToken(request.getUsername(), jwtProvider.getRefreshTokenTtl());
        String previousToken = loginSessionService.bindSession(request.getUsername(), token,
                jwtProvider.getRefreshTokenTtl());
        if (StringUtils.hasText(previousToken)) {
            tokenStore.removeAccessToken(previousToken);
        }
        tokenStore.cacheAccessToken(token, user.getUsername(), jwtProvider.getAccessTokenTtl());
        tokenStore.cacheRefreshToken(user.getUsername(), refreshToken, jwtProvider.getRefreshTokenTtl());
        log.info("User {} login success from ip {}", user.getUsername(), clientIp);
        return new AuthResponse(token, refreshToken, expireAt);
    } finally {
        /*释放锁*/
        loginSessionService.releaseLoginLock(request.getUsername());
    }
}
```

```java
/*对应的方法*/
private String resolveClientIp(HttpServletRequest request) {
    /*从请求获取用户ip*/
    String header = request.getHeader("X-Forwarded-For");
    if (StringUtils.hasText(header)) {
        return header.split(",")[0].trim();
    }
    return request.getRemoteAddr();
}
```

```java
/*校验ip是否在白名单和黑名单中*/
enforceIpPolicy(clientIp);
/*对应方法*/
private void enforceIpPolicy(String ip) {
    /*和ip名单进行校验*/
    SecurityPolicyProperties.IpPolicy ipPolicy = policyProperties.getIp();
    if (ipPolicy.getBlacklist() != null && ipPolicy.getBlacklist().contains(ip)) {
        throw new BusinessException(ErrorCode.IP_NOT_ALLOWED);
    }
    if (ipPolicy.getWhitelist() != null && !ipPolicy.getWhitelist().isEmpty()
        && !ipPolicy.getWhitelist().contains(ip)) {
        throw new BusinessException(ErrorCode.IP_NOT_ALLOWED);
    }
}
```

```java
/*密码是否合法*/
validatePasswordComplexity(request.getPassword());
/*这里是根据自己定义的密码策略进行检验*/
private void validatePasswordComplexity(String password) {
    SecurityPolicyProperties.PasswordPolicy policy = policyProperties.getPassword();
    if (password == null || password.length() < policy.getMinLength()) {
        throw new BusinessException(ErrorCode.PASSWORD_NOT_COMPLEX);
    }
    if (policy.isRequireUpper() && password.chars().noneMatch(Character::isUpperCase)) {
        throw new BusinessException(ErrorCode.PASSWORD_NOT_COMPLEX);
    }
    if (policy.isRequireLower() && password.chars().noneMatch(Character::isLowerCase)) {
        throw new BusinessException(ErrorCode.PASSWORD_NOT_COMPLEX);
    }
    if (policy.isRequireNumber() && password.chars().noneMatch(Character::isDigit)) {
        throw new BusinessException(ErrorCode.PASSWORD_NOT_COMPLEX);
    }
    if (policy.isRequireSymbol()
        && password.chars().noneMatch(ch -> !Character.isLetterOrDigit(ch))) {
        throw new BusinessException(ErrorCode.PASSWORD_NOT_COMPLEX);
    }
}
```

```java
/*检查登录用户*/

/*redis锁，用于限制登录用户，只允许一个用户登录*/
public void acquireLoginLock(String username) {
    /*setIfAbsent 当值存在时，do nothing ，当值不存在时，Save and return ture*/
    Boolean success = redisTemplate.opsForValue()
        .setIfAbsent(LOGIN_LOCK_PREFIX + username, "1", LOCK_EXPIRE_SECONDS, TimeUnit.SECONDS);
    /*if return true , 说明没有用户登录，则加锁。else TOO_MANY_REQUESTS*/
    if (!Boolean.TRUE.equals(success)) {
        throw new BusinessException(ErrorCode.TOO_MANY_REQUESTS);
    }
}
```

```java
public void ensureLoggedOut(String username) {
    String current = redisTemplate.opsForValue().get(SESSION_PREFIX + username);
    if (current != null) {
        throw new BusinessException(ErrorCode.ACCOUNT_ALREADY_LOGIN);
    }
}
```

```java
private IamUser getUserByUsername(String username) {
    LambdaQueryWrapper<IamUser> wrapper = new LambdaQueryWrapper<>();
    wrapper.eq(IamUser::getUsername, username).last("LIMIT 1");
    IamUser user = userMapper.selectOne(wrapper);
    if (user == null) {
        throw new BusinessException(ErrorCode.UNAUTHORIZED);
    }
    return user;
}
```

```java
/**
* 检验用户是否被锁定
* @param user
*/
private void ensureAccountAvailable(IamUser user) {
    LocalDateTime lockedUntil = user.getLockedUntil();
    if (lockedUntil != null && lockedUntil.isAfter(LocalDateTime.now())) {
        throw new BusinessException(ErrorCode.ACCOUNT_LOCKED);
    }
}
```

```java
/*判断密码是否过期*/
ensurePasswordNotExpired(user);

 /**
* 检验密码是否过期
* @param user
 */
private void ensurePasswordNotExpired(IamUser user) {
    /*规定的密码存在时间*/
    int expireDays = policyProperties.getPassword().getExpireDays();
    if (expireDays <= 0) {
        return;
    }
    /*上次修改密码时间*/
    LocalDateTime updatedAt = user.getPasswordUpdatedAt();
    if (updatedAt == null) {
        return;
    }
    /*进行判断*/
    if (updatedAt.plusDays(expireDays).isBefore(LocalDateTime.now())) {
        throw new BusinessException(ErrorCode.PASSWORD_EXPIRED);
    }
}
```

若全部都校验通过，则和数据库对比密码的正确性

```java
if (!isPasswordMatched(request.getPassword(), user.getPassword())) {
    /*密码错误需要进行的业务*/
    handleLoginFailure(user);
    throw new BusinessException(ErrorCode.UNAUTHORIZED);
}

private void handleLoginFailure(IamUser user) {
    int count = user.getFailedLoginCount() == null ? 0 : user.getFailedLoginCount();
    count++;
    int maxFailures = policyProperties.getLogin().getMaxFailures();
    LambdaUpdateWrapper<IamUser> wrapper = new LambdaUpdateWrapper<>();
    wrapper.eq(IamUser::getId, user.getId());
    /*如果密码错误次数超过最大限制，怎lock账户getLockMinutes()时间*/
    if (count >= maxFailures) {
        /*超过最大次数后设置锁定时间*/
        LocalDateTime lockedUntil = LocalDateTime.now()
            .plusMinutes(policyProperties.getLogin().getLockMinutes());
        wrapper.set(IamUser::getFailedLoginCount, 0)
            .set(IamUser::getLockedUntil, lockedUntil);
        user.setFailedLoginCount(0);
        user.setLockedUntil(lockedUntil);
    } else {
        wrapper.set(IamUser::getFailedLoginCount, count);
        user.setFailedLoginCount(count);
    }
    userMapper.update(null, wrapper);
}
```

如果密码匹配成功，则需要重置登录状态。比如：如果前面有密码错误次数，成功之后，则需要将次清零

```java
resetLoginState(user, clientIp);
/*处理密码校验成功后的信息*/
private void resetLoginState(IamUser user, String ip) {
    LambdaUpdateWrapper<IamUser> wrapper = new LambdaUpdateWrapper<>();
    wrapper.eq(IamUser::getId, user.getId())
        .set(IamUser::getFailedLoginCount, 0) /*失败次数*/
        .set(IamUser::getLockedUntil, null)
        .set(IamUser::getLastLoginIp, ip) /*获取ip*/
        .set(IamUser::getLastLoginTime, LocalDateTime.now());
    if (user.getPasswordUpdatedAt() == null) {
        wrapper.set(IamUser::getPasswordUpdatedAt, LocalDateTime.now());
    }
    userMapper.update(null, wrapper);
}
```
